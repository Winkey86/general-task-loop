# General Task Loop

Два скилла для работы над задачами в Claude Code и Codex. В качестве входа подойдут описание, файл или ссылка на issue. Можно передать работу другой сессии по сохранённому состоянию и артефактам задачи.

| Скилл | Когда использовать | Что получится |
| --- | --- | --- |
| [`my-task-loop`](skills/my-task-loop/SKILL.md) | Нужно согласовать решения, постановку и реализацию по этапам | Постановка, спека и задачи Spec Kit, реализация, ревью и приёмка |
| [`sam-reshu`](skills/sam-reshu/SKILL.md) | Границы задачи понятны и агенту можно делегировать реализацию | Компактный план, проверенная реализация и, если согласовано, PR/MR с результатом CI |

## Установка

В корне клонированного репозитория выполни команды ниже. Для Claude Code подставь `$HOME/.claude/skills` в `skills_dir`. Установи оба каталога вместе: `sam-reshu` читает общий протокол из `my-task-loop`. Если эти имена уже заняты, `ln` сообщит о конфликте. Проверь существующие ссылки перед заменой.

```sh
skills_dir="$HOME/.agents/skills"  # Codex
mkdir -p "$skills_dir"
ln -s "$PWD/skills/my-task-loop" "$PWD/skills/sam-reshu" "$skills_dir/"
```

Открой новую сессию в репозитории задачи и вызови скилл явно.

| Claude Code | Codex |
| --- | --- |
| `/my-task-loop fix-login Исправить возврат после входа` | `$my-task-loop fix-login Исправить возврат после входа` |
| `/sam-reshu fix-login Исправить возврат после входа` | `$sam-reshu fix-login Исправить возврат после входа` |

## Как идёт работа

**`my-task-loop`** проводит по цепочке от разбора задачи до итогового отчёта. Сначала согласуются решения, затем постановка и спека. За ними идут согласование объёма, реализация, локальная приёмка, ревью и приёмка на стенде. Каждый следующий этап начинается по твоей команде. [Этапы](skills/my-task-loop/references/stages.md)

**`sam-reshu`** один раз согласует границы, критерии и действия снаружи рабочего дерева. После подтверждения агент ведёт работу сам и возвращается с результатом или вопросом, от которого зависит продолжение. [Фазы и стоп-условия](skills/sam-reshu/SKILL.md)

`my-task-loop` использует [GitHub Spec Kit](https://github.com/github/spec-kit), если его интеграция установлена в репозитории задачи. Скилл также описывает, как составить `spec.md`, `plan.md` и `tasks.md` вручную. У `sam-reshu` один компактный `plan.md` с критериями, решениями и проверками.

## Передача работы

Для передачи задачи вызови тот же скилл с тем же ключом в другой сессии Claude Code или Codex. Если меняешь машину или checkout, передай путь к файлу состояния, ветку или ссылку на PR/MR и упомянутые в состоянии документы. [Формат состояния и правила возобновления](skills/my-task-loop/references/workflow.md)

Для передачи разработки **самого пакета** начни с [постановки](specs/001-general-task-loop/postanovka.md). Критерии находятся в [спецификации](specs/001-general-task-loop/spec.md), устройство и проверка — в [плане](specs/001-general-task-loop/plan.md), состояние работ — в [задачах](specs/001-general-task-loop/tasks.md).
